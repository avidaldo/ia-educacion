# Galician conventions for the course site

Write normative Galician (RAG, *Normas ortográficas e morfolóxicas do idioma galego*, 2003, with the 2012 update), in a plain, direct register addressed to teachers with *ti* (as the Spanish addresses them with *tú*).

## Anglicisms and product terms

- Unadapted English words go in *italics*: *prompt*, *chatbot*, *few-shot*, *exit ticket*. Not acronyms (GIFT, XML, API) nor product names (Moodle, ChatGPT, NotebookLM).
- They take the gender of their Galician equivalent, adjectives included: *unha skill* (habilidade), *o notebook* (caderno).
- **Common use beats that rule** when the teacher has decided so; such decisions are recorded in the glossary (for example *o prompt*, masculine as in common use, although its equivalent *instrución* is feminine; *fork* is masculine).
- Prefer an established Galician word when there is one: retroalimentación (not *feedback* in prose), ligazón (not *link*).

## Typography

- «Comiñas latinas» first, “inglesas” inside them.
- Ordinals: 1.º, 2.ª; «p. ex.» for *por exemplo*; decimal comma; a space before %: 25 %.
- Titles in sentence case, as in Spanish.

## Grammar points where calques from Spanish creep in

- Pronoun placement: enclisis in affirmative main clauses (*Pídelle*, *Faime 3 preguntas*, *indícao*), proclisis after negation, interrogatives and many conjunctions/adverbs (*non o sabes*, *se non o sabes*, *que o modelo o faga*).
- Contractions: *ao*, *á*, *polo*, *pola*, *co*, *coa*, *cun*, *cunha*, *no*, *na*, *dun*, *dunha*.
- Infinitive with person when the subject differs: *para o modelo entender* is correct, but prefer *para que o modelo entenda* in instructions.
- Possessives take the article: *o teu prompt*, *a túa clase*.
- No *usted* forms; imperatives with *ti*: *Pide*, *Inclúe*, *Compara*, *Revisa*.

## Frequent Spanish (and Portuguese) forms to avoid

| Avoid | Use |
| --- | --- |
| sin, hasta, también, todavía, entonces, mientras, luego (= then) | sen, ata, tamén, aínda, entón, mentres, logo |
| aunque, pues, cuando, donde, como (= like) | aínda que, pois, cando, onde, coma/como |
| restricción, instrucción, construcción (double c) | restrición, instrución, construción — but acción, dirección, selección, corrección keep *cc* |
| buen (before a noun) | bo: *bo uso*, *un bo prompt* |
| librería (software) | biblioteca |
| llevar a cabo | levar a cabo |
| nível, fichero (Portuguese / Spanish) | nivel, ficheiro |
| el/la (articles) | o/a |
| -aje (aprendizaje, lenguaje) | -axe, feminine: *a aprendizaxe*, *a linguaxe* |
| -ble with Spanish spelling (disponible) | dispoñible, posible, verificable |
| ventaja, desventaja | vantaxe, desvantaxe (feminine) |
| asignatura | materia |
| plantilla, patrón (template, pattern) | modelo, formato, estrutura (see the glossary) |
