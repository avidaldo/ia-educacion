Every link on this list was opened when the list was reviewed (date above) and is here for a specific reason. Primary sources are preferred: the provider’s documentation, the text of the rule or the original article. The module pages also cite their own sources in footnotes.

## AI in education

- [The European Commission’s ethical guidelines for educators](https://data.europa.eu/doi/10.2766/7967834) (2026): the European reference framework for deciding which uses are acceptable in class.
- [Juan José de Haro’s blog](https://educacion.bilateria.org/author/jjdeharo) (in Spanish): experiences and AI tools for the classroom.
- What the law requires and what is a matter of prudence is in [Ethics and law](../etica-legal/index.md) and [Legal framework](../etica-legal/normativa.md), with the official texts quoted.

## Prompts

- [Prompt Engineering Guide](https://www.promptingguide.ai/): a collection of techniques with examples.
- [Prompt.org.es](https://www.prompt.org.es/) (in Spanish): prompting resources.
- [OpenAI’s guide](https://platform.openai.com/docs/guides/prompt-engineering), [Anthropic’s guide](https://docs.claude.com/en/docs/build-with-claude/prompt-engineering/overview) and [Gemini’s guide](https://ai.google.dev/gemini-api/docs/prompting-strategies): each provider explains how to write prompts for its models. They are documentation for developers, but the advice works for any user.
- [OpenAI’s guide to reasoning models](https://platform.openai.com/docs/guides/reasoning): how to give tasks to these models: a clear goal, constraints and an output format, instead of dictating the steps. It is developed in [Advanced techniques](../prompts/avanzado.md).
- [*The Prompt Report*](https://arxiv.org/abs/2406.06608) (Schulhoff et al., 2024): a systematic review of prompting techniques. For those who want the academic view.

## Skills and automation

- [Agent Skills](https://agentskills.io): the open specification of the skill format, with examples. It is explained in [Assistants and skills](../skills/index.md).
- [n8n documentation](https://docs.n8n.io/): the official reference for the automation tool of the [Automations](../n8n/index.md) module.

## Tools

- [Gemini Notebook help](https://support.google.com/gemininotebook/) (formerly NotebookLM): what each plan allows and how sources work. More in [Gemini notebooks](../notebooks/index.md).
- [Canva for Education](https://www.canva.com/education/) and [Gamma](https://gamma.app): for presentations and visual material. Text-based alternatives, which can be versioned and do not depend on an account: [reveal.js](https://revealjs.com) and [Marp](https://marp.app). The method is in [Presentations](../webs-educativas/presentaciones.md).

## Programming with AI

- [*Not all AI-assisted programming is vibe coding*](https://simonwillison.net/2025/Mar/19/vibe-coding/) (Simon Willison, 2025): the difference between programming with the help of AI and letting it write code without reading it.
- [*The lethal trifecta*](https://simonwillison.net/2025/Jun/16/the-lethal-trifecta/) (Simon Willison, 2025): the combination of private data, untrusted content and the ability to communicate externally that makes an agent vulnerable. It helps to understand the risks of [agentic browsers](../navegadores-agenticos/index.md).

## Moodle

- [Aiken format](https://docs.moodle.org/en/Aiken_format), [GIFT format](https://docs.moodle.org/en/GIFT_format) and [Moodle XML format](https://docs.moodle.org/en/Moodle_XML_format): the official documentation of each question import format.
- [`tests-generator`](https://github.com/avidaldo/tests-generator): this course’s question generator. The method is in [Quizzes for Moodle](../tests-moodle/index.md).
